Staff data and timetable identity are separate

Employee Code is the unique institutional staff number. Teacher Short Name / Timetable Code (for example RC2, ML) is optional here and remains only a timetable reference. Staff save/import operations update the personnel directory only and do not alter timetable records, allocations, proxy records or active timetable identity. Local Appointment is stored separately; reports can show (LA) after the person's name without changing the actual Name field.
