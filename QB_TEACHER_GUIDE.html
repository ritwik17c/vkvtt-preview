Question Bank & Paper Builder

Teacher User Guide · Vivekananda Kendra Vidyalaya, Nalbari · Preview 2
Core workflow: Teacher creates → saves draft → submits → Subject Coordinator verifies → verified question enters the Question Bank → verified count contributes to the Principal's leaderboard.

1. Opening the Module

  1. Sign in to VKVTT using your authorised Google account.
  2. In My Area / Section 2, open Question Bank & Paper Builder.
  3. The tile is shown only to linked teaching staff. Non-teaching staff cannot access this module.

2. Adding a Question

  1. Open Add Question.
  2. Choose Assist, Auto or Manual.
  3. Select the dictation language: English, Assamese, Hindi or Sanskrit.
  4. Dictate, type or paste the question. In voice mode you may say class, subject, chapter, marks and difficulty before the question.
  5. Use Compose & Categorise. Verify every suggested field.
  6. For Mathematics/Science, use the symbol toolbar when needed.
  7. Add the answer/expected answer and marking scheme where appropriate.
Important: Never submit a mathematical expression, Sanskrit passage, Assamese spelling or scientific symbol without visually checking the final text.

3. Draft vs Submit

Save Draft keeps the question in your personal working history. Submit to Subject Coordinator sends it for academic verification. Only verified questions enter the shared approved Question Bank and count towards verified-question contribution.

4. If a Question Is Returned

  1. Open My Submission History.
  2. Read the Subject Coordinator's correction note.
  3. Choose Edit & Resubmit.
  4. Correct the question and submit again.

The previous workflow is retained; it is not erased by resubmission.

5. My Submission History

Use filters for class, subject, status and question text. Each entry shows its present status and workflow trail—submission, return, resubmission and verification.

6. Verified Question Bank

Use class, subject, difficulty and search filters to find suitable verified questions. The shared bank contains coordinator-verified questions only.

7. Subject Coordinators

If you are assigned as a Subject Coordinator, a Review Questions tab appears. Verify academic correctness, wording, marks/difficulty, answer and marking scheme. Choose Verify & Accept only after checking the question. If correction is required, choose Return for Correction and enter a clear note.

8. Building a Question Paper

  1. Open Build Paper.
  2. Select a template, class, subject and time.
  3. Load verified questions.
  4. Add suitable questions to the paper.
  5. Check total marks and question order.
  6. Use Print / Save PDF for the current paper output.

9. Importing Questions

  1. Open Import / Export.
  2. Download the Excel import template.
  3. Keep the given column headings.
  4. Fill Class, Subject, Chapter, Question, Marks, Type, Difficulty, Answer and Marking Scheme.
  5. Import the Excel file.

Imported questions first enter as Drafts; review them before submission.

10. Exporting

Use Export My Questions to download your question records in Excel. The Principal/Admin has separate institutional exports and filtered reports.

11. Voice Tips

  • Speak clearly and in short, complete phrases.
  • Say metadata first when possible: “Class Ten, Mathematics, Quadratic Equations, two marks, moderate…”
  • Use Manual mode when exact teacher wording must be preserved.
  • Use Assist mode for gentle correction while retaining teacher control.
  • Use Auto mode when you want the app to organise and refine the wording more actively.

12. Status Meanings

Draft — not submitted. Pending Review — with Subject Coordinator. Returned — correction required. Verified — accepted into the approved Question Bank and counted as a verified contribution.

Remember: Quality matters. The verified-question leaderboard is intended to recognise useful, academically sound contributions—not repeated or near-duplicate questions.
